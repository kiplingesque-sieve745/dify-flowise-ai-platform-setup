## 🔧 About the platform

This software provides a local environment to run Dify and Flowise on your Windows computer. These tools allow you to create artificial intelligence applications. You drag and drop blocks to build workflows. You connect data sources to large language models. You manage your AI projects in one place.

## 💻 System requirements

Your computer needs specific hardware to run these AI tools. Check your system specifications before you start.

- Operating System: Windows 10 or Windows 11.
- Processor: Intel Core i5 or better.
- Memory: 16 Gigabytes of RAM minimum.
- Storage: 20 Gigabytes of available space on a solid-state drive.
- Network: A stable internet connection for initial setup and downloading AI models.

## 🏗️ Building your first workflow

The platform landing page shows two main areas: Dify and Flowise. 

### Using Flowise

Flowise lets you build visual chains for language models. 
1. Click the "Flowise" tab on the main dashboard.
2. Click "Create New" to start a blank project.
3. Look at the canvas. The left panel shows available nodes. These include chat memories, document loaders, and model providers.
4. Drag a node onto the white space.
5. Connect the colored dots on the nodes to link your logic.
6. Click the "Save" button to keep your progress.
7. Click the green "Chat" button to test your workflow.

### Using Dify

Dify handles complex AI applications and RAG, also known as Retrieval-Augmented Generation.
1. Click the "Dify" tab.
2. Select "Create App."
3. Choose a template if you want to save time. Templates cover tasks like customer support bots or document summarizers.
4. Input your API keys in the settings menu. You need a key from an AI provider like OpenAI or Anthropic.
5. Connect your documents in the document management section.
6. Publish your application to generate a shareable web link.

## 📝 Troubleshooting common issues

If you encounter problems, look at these steps.

### Application fails to start
Ensure no other software uses port 3000. Close other developer tools or web servers before you open this platform. Restart your computer if a background process hangs.

### Cannot connect to AI provider
Check your API keys. Copy and paste them into the settings menu to avoid typos. Ensure your internet connection is active. 

### Workflow displays an error
Check your node connections. Every node requires a valid input and output to function. Look at the console window for red text. This text often explains why a process failed.

### High memory usage
Large AI tasks consume significant hardware resources. Close other applications like web browsers or video editors while you build your workflows. This gives the AI platform the memory it needs to process data.

## 📁 Managing your data

The software stores your project data locally. Back up your "data" folder regularly. Find this folder inside the installation directory. Copy the contents to a cloud drive or an external hard drive. This prevents data loss if your computer fails.
